# 🤖 AI Personal Assistant Landing Page

A modern and responsive landing page for an AI-powered personal assistant. This project was created as **Level 1 – Task 1** during my internship at **Oasis Infobyte**.

## 📌 Internship Details

- **Organization:** Oasis Infobyte
- **Level:** Level 1
- **Task:** Task 1
- **Project:** AI Personal Assistant Landing Page
- **Technologies Used:** HTML5 & CSS3

## 🚀 Project Overview

This project is a visually appealing and responsive landing page designed for an AI-powered personal assistant platform.

The website features a modern user interface with gradient effects, glassmorphism cards, responsive layouts, and attractive sections to showcase the features and benefits of an AI assistant.

- Responsive Navigation Bar

- CSS-based 3D Gradient Illustration
- Trusted Companies Section
- Six Glassmorphism Feature Cards
