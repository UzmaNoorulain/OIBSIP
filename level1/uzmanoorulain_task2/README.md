# 💼 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website created to showcase my skills, projects, and experience as a Full-Stack Developer.

This project was completed as **Level 1 – Task 2** during my internship at **Oasis Infobyte**.

---

## 📌 Internship Details

- **Organization:** Oasis Infobyte
- **Level:** Level 1
- **Task:** Task 2
- **Project:** Personal Portfolio Website

---

## 🚀 Project Overview

This project is a personal portfolio website designed to showcase my professional profile, technical skills, and featured projects.

The portfolio includes a modern dark-themed interface with gradient effects, animations, interactive elements, and responsive design. It also features a 3D animated background created using Three.js and tilt effects for an enhanced user experience.

- 📱 Fully Responsive Design
- 🧭 Responsive Navigation Bar
