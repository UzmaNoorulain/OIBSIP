# 🌡️ Temperature Converter Website

A simple, modern, and responsive Temperature Converter web application that allows users to instantly convert temperatures between Celsius, Fahrenheit, and Kelvin.

This project was completed as **Level 1 – Task 3** during my internship at **Oasis Infobyte**.

---

## 🚀 Project Overview

The Temperature Converter is a user-friendly web application designed to convert temperature values between three commonly used temperature units:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

Users can enter a temperature value, select the input unit, and instantly view the equivalent values in all three temperature units.

---

## ✨ Features

- 🌡️ Convert temperatures between Celsius, Fahrenheit, and Kelvin
- 🔄 Displays results for all three units simultaneously
- 🖥️ Clean and modern user interface
- 📱 Responsive design
- ⚡ Instant temperature conversion
- ❌ Input validation and error handling
- 🎨 Attractive background design with CSS effects
