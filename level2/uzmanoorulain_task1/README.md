# 🧮 Calculator Web Application

A simple, modern, and responsive calculator web application built using HTML, CSS, and JavaScript. This calculator performs basic arithmetic operations and provides an interactive user interface.

This project was completed as **Level 2 – Task 1** during my internship at **Oasis Infobyte**.

---

## 📌 Internship Details

- **Organization:** Oasis Infobyte
- **Level:** Level 2
- **Task:** Task 1
- **Project:** Calculator Web Application

---

## 🚀 Project Overview

The Calculator Web Application allows users to perform basic mathematical calculations easily and efficiently.

The application includes number buttons, arithmetic operators, a decimal button, a clear button, and a backspace button. The display shows the mathematical expression and the calculated result.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal Number Support
- 🧹 Clear Calculator Functionality
- ⌫ Backspace Functionality
- 🟰 Calculate Results
- 🖥️ Displays Mathematical Expressions
- 📱 Responsive User Interface

---

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the calculator
- **CSS3** – For designing and styling the user interface
- **JavaScript** – For implementing calculator functionality and handling user interactions
