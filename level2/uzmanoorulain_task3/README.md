## 🚀 Project Overview

TaskFlow is a simple and responsive task management application that allows users to organize their daily tasks efficiently.

Users can add new tasks, mark tasks as completed, search for tasks, monitor their progress, and clear completed tasks. The application also displays real-time statistics for pending, completed, and total tasks.

---

## ✨ Features

- ➕ Add new tasks
- 📝 View pending tasks
- ✅ Mark tasks as completed
- 🔍 Search tasks
- 📊 Track pending, completed, and total tasks
- 📈 Real-time task progress indicator
- 🗑️ Clear completed tasks
- 📅 Display the current date
- 🔔 Toast notifications
- 📱 Responsive and user-friendly interface
