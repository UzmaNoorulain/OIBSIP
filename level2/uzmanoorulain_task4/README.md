# 🔐 SecureAuth – Login Authentication System

A simple and responsive Login Authentication System that allows users to register, log in, and access a protected dashboard.

This project was completed as **Level 2 – Task 4** during my internship at **Oasis Infobyte**.

- **Organization:** Oasis Infobyte

- **Project:** Login Authentication System
- **Application Name:** SecureAuth

---

## 🚀 Project Overview

SecureAuth is a front-end authentication system designed to demonstrate the basic functionality of user registration and login.

The application provides separate pages for user registration and login. After successful authentication, users can access their dashboard.

The project focuses on implementing authentication-related functionality using JavaScript along with a clean and responsive user interface.

---

## ✨ Features

- 🔐 User Login System
- 📝 User Registration System
- 📧 Email Input Validation
- 🔑 Password Authentication
- ❌ Error Message Handling
- 📊 Protected Dashboard
- 🚪 Logout Functionality
- 📱 Responsive Design
- 🎨 Clean and Modern User Interface
